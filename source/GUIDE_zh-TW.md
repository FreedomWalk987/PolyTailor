# PolyTailor 使用說明

給 Blender 4.5 以上編輯模式使用的重拓撲與建模工具。免費、開源（GPL-3.0-or-later）。
介面支援繁體中文與英文，預設跟隨 Blender 的語言。

## 安裝與開始

1. 從偏好設定的「取得擴充套件 › 從磁碟安裝」選取 PolyTailor 的 zip，然後啟用 PolyTailor。
2. 物件模式：Shift＋A > 網格 > 「新網格（3D）」或「重拓撲網格」（N 側欄 PolyTailor 分頁也有）。「新網格（3D）」在 3D 游標處新增空白網格並使用 3D 模式；「重拓撲網格」在作用中物件上新增空白網格並使用重拓撲模式；來源物件設定維持不變（沒設定時，所有可見物件都是來源）。隨即進入編輯模式與建立工具，Ctrl＋左鍵放下第一個頂點。
3. 選取網格、進入編輯模式，在左側工具列選擇 PolyTailor 工具。按 W 開啟工具輪盤；N 側欄也有 PolyTailor 面板。
4. 視窗左下角顯示目前的工具、模式與狀態；目前工具的按鍵列在 Blender 底部的狀態列。附加元件偏好設定的「視窗說明」預設為「精簡」；改為「完整」時左下角也會列出按鍵，「關閉」則不顯示。

需要 Blender 4.5 以上；已在 Blender 5.2.3 測試，僅在 Windows 上測試。

圖示顏色在附加元件偏好設定的「圖示顏色」：「自訂」（預設）使用 PolyTailor 自己的顏色，可在下方修改；「原生」像 Blender 原生圖示一樣跟著主題變色。

## 先選對模式：3D 或重拓撲

- **3D**：做自己的模型。不吸附其他物件，自動合併關閉（建立工具拖曳結束在頂點上時仍會與它合併，和在那裡點擊一樣）。新檔預設為 3D。
- **重拓撲**：只在「照著另一個模型重新布線」時使用，新點和移動的點會貼到來源模型表面。
- 「自動合併」在重拓撲模式下所有工具預設開啟（拖動、放置、移動頂點時才會合併，筆刷不會合併），3D 下關閉。自動合併關閉時，建立工具拖曳結束在頂點上仍會與它合併，和點擊相同。
- 「修正面屬性」維持你自己的設定（Blender 預設關閉），PolyTailor 不會更改。
- 做自己的模型卻開著重拓撲，點會被吸到別的物件上或停在邊緣，看起來像卡住；切回 3D 即可。
- 切換位置：W 輪盤右上的「吸附」區、N 側欄的「吸附」面板或工具標頭。在 Blender 原生工具中點「重拓撲」會自動切到建立工具；切回原生工具或按 Tab 離開編輯模式時，會回到 3D 並還原你自己的吸附設定。

## 模式與基本操作

| 工具／模式 | 用途與主要操作 |
|---|---|
| 3D | 自由建模，不吸附其他物件。 |
| 重拓撲 | 配合來源物件做重拓撲；確認吸附磁鐵及來源設定。 |
| 建立（Build） | 按住 Ctrl 預覽，Ctrl＋左鍵建立；繼續拖曳以放置新幾何。面型：三角／四邊或四邊形；單一頂點：曲線筆劃；在選取邊或邊鏈附近 Ctrl＋拖曳：四邊面條帶。 |
| 建立工具的移動 | G 移動，X／Y／Z 限制軸向。O 切換比例化編輯；滾輪調半徑，Shift＋O 切換衰減。 |
| 框選（建立與填補） | 左鍵拖曳移動選取或滑鼠下的元素，從空白處拖曳為框選；Shift＋拖曳加選框選；Shift＋Ctrl＋拖曳減選框選（單獨按 Ctrl 是預覽）。 |
| 放鬆（Relax） | 按住左鍵放鬆；按住 Ctrl 拖曳可暫時切為調校，放開 Ctrl 繼續放鬆。左鍵是穩健放鬆（修正歪斜的四邊面；預設的「均勻間距」會把每排間距調平均）；按住 Alt＋左鍵是格線放鬆（邊長拉平均、四邊形拉方正、線圈拉直），沿用同一套筆刷與遮罩設定。 |
| 調校（Tweak） | 按住左鍵拖動筆刷內頂點。 |
| 筆刷設定 | F 半徑、Shift＋F 力量、Ctrl＋F 衰減。放鬆與調校的出廠半徑都是 100 px。 |
| 選取模式 | W 輪盤右側的「選取模式」：點／線／面，Shift＋點可同時開啟多種。 |
| 放鬆選取（建立與填補） | 建立與填補工具中 Alt＋滾輪；預設使用「筆刷放鬆」（與放鬆筆刷同一套演算法）。可在工具設定或工具標頭的「Alt＋滾輪平滑」選單改用格線放鬆、LoopTools 放鬆或原生。 |
| 中鍵切換工具 | 預設開啟。單擊中鍵：在建立與筆刷（放鬆／調校）之間切換；Ctrl＋單擊中鍵：在建立與填補之間切換。按住中鍵拖曳仍是旋轉視角，Ctrl＋中鍵拖曳仍是縮放。可在附加元件偏好設定關閉。 |
| 取消當前操作 | Esc 或右鍵。混合放鬆／Ctrl 調校的筆劃會整筆還原。 |

待命筆刷按右鍵時，先暫停筆刷圓圈繪製，再由 Blender 開啟原本的右鍵選單。
選單結束後，回到視窗移動滑鼠、開始下一筆或按 F 調整時恢復；工具與設定保留。
正在按住左鍵刷動時，右鍵仍是取消整筆筆劃。

## W 輪盤

在編輯模式按 W，於滑鼠位置開啟輪盤：上方是「固定工具」（釘選／黏合），右上是「吸附」（含 3D／重拓撲切換），右側是「選取模式」，左上「建立」、左側「填補」、左下「放鬆／調校」，下方是目前工具的設定。

- 切換工具：點選工具，或朝工具方向移動後點擊；也可按住 W 朝工具方向移動再放開 W；或按 7（建立）、4（填補）、1（放鬆）。只移向工具不會切換。
- 調整設定時輪盤保持開啟：數值可左右拖曳（Shift 較精細）、在數值上滾動滾輪，或雙擊後輸入（Enter 確認、Esc 取消）。
- Esc、右鍵或點擊輪盤外部即關閉輪盤。
- Shift＋W 開啟包含所有設定的面板。

## 固定工具：釘選與黏合

輪盤與側欄使用同一排兩組按鈕：**釘選／解除**，以及 **黏合／解除**。

| 操作 | 行為與顯示 |
|---|---|
| 釘選（Pin） | 保護選取頂點，不受放鬆、調校與 Alt＋滾輪移動，以強調色圓點標示。左組「解除」移除選取頂點的釘選。 |
| 黏合（Glue） | 選取相連的現有邊，將整條鏈固定形狀與尺寸，以強調色連續線標示；整組仍可移動、旋轉，也可用於封閉的線圈。 |
| 解除黏合 | 選取要解除的部分，再按右組「解除」：兩端都選取的黏合邊會解除，其餘相連的部分仍各自黏合；只選一個頂點時，只解除該頂點。全選後按「解除」可解除整組。 |
| 多組黏合 | 不相連的選取各自成組。選取連接兩組的邊鏈後按「黏合」，可合併群組。 |

黏合對放鬆、調校、Ctrl 暫時調校及 Alt＋滾輪放鬆生效，可能連同筆刷範圍外的同組成員一起移動。
它不會建立新邊，也不會限制 Blender 原生建模工具或其他附加元件對形狀的編輯；每筆操作以起筆時的形狀作為固定參考。

同組含釘選、隱藏點、被遮罩排除的點或鎖定邊界時，原有限制優先，整組可能保持原位。
若固定形狀與貼面、鏡像截割或邊界滑動無法同時滿足，黏合也可能保持原位。
很長的黏合鏈需要整組參與計算，速度可能下降。

## 放鬆的注意事項

- 邊界有移動、滑動、鎖定三種模式，出廠預設為移動。
- 「均勻間距」預設開啟，會改變四邊面的參考尺寸；它是效果選項，不是效能開關。對局部比例有要求時，可比較開關結果。
- 自由邊界的孔洞仍可能改變大小。可用釘選固定位置，或用黏合固定整圈形狀。
- 大群組、複雜來源物件、修改器及其他附加元件的投影更新都可能增加耗時。

## 選取快捷鍵

一般單擊、Shift 加選與循環邊選取，會交給你自己的 Blender 快捷鍵設定（包含選取類附加元件）。PolyTailor 只保留建立與填補的左鍵拖曳移動／空白處框選、Shift＋拖曳加選框選、Shift＋Ctrl＋拖曳減選框選、Ctrl 建模，以及筆刷的左鍵。若其他附加元件使用相同手勢，可能需要調整其中一方的快捷鍵。

## 問題回報

請附下列資訊；不需要提供機密原檔，可以先嘗試用新建網格重現。

- PolyTailor 版本（偏好設定中可見）；Blender 完整版本與作業系統。
- 使用的工具、3D／重拓撲模式、操作按鍵與重現步驟。
- 頂點／面數、黏合群組數及大約每組頂點數。
- 預期與實際結果；卡頓發生在哪一階段。
- 新檔是否能重現、相關修改器／投影附加元件是否影響結果。
- 錯誤訊息；可公開的錄影或截圖。

## 填補（Fill）

W 輪盤左側為「填補」。填補沿用外框現有的邊與頂點。

### 孔洞與「開放邊」是什麼

可以填補：模型上缺面的孔洞，或一圈只有邊、尚未有面的封閉線框。
「開放邊」表示邊只連接零個或一個面；它們仍須圍出完整的一圈。
單獨一條未封口的線或兩條等待橋接的線，不會自動猜測要怎麼連接（同時選取多個封閉外框請見下方「多面板填補」）。
線框被一排面切開、或兩個洞共用一個點時，每個被圍起來的區域都可以分別填補。
先接好缺口；狀態提示會說明不能填補的原因。

### 基本操作

1. 選取一圈封閉外框（孔洞或封閉線框），再按住 Ctrl；已選外框優先，滑鼠在外框外仍有預覽。
   沒有選取外框時，按住 Ctrl 把滑鼠移進孔洞或封閉線框內。
2. 等待預覽完成（預覽的面與線使用偏好設定的「預覽面填色」與「預覽線條顏色」）；計算期間會顯示提示，可以移到別處、放開 Ctrl 或按 Esc 取消。
3. Ctrl＋滾輪換方案：逐一切換找到的結果。
4. Ctrl＋左鍵建立預覽中的面；保留原有外框頂點。每次填補是一個復原步驟。
5. 放開 Ctrl 結束預覽；Esc 也可結束。已確認的補面保留，可用 Ctrl＋Z 復原。

填補會找出多種方案：照周圍的四邊面延續網格；找兩組對邊點數相等的 4 個角，
鋪成沒有極點的規則網格（帶狀、彎管、近似長方形）；其他圖樣；很凹的外形會自動分區。
方案一找到就會出現，搜尋結束後重新排序；Ctrl＋滾輪換方案。
提示列以短詞標示每個方案的特性：「沿外框」「少極點」「均勻」「切割」。
同一個外形不論物件怎麼擺放，結果都相同。
填補會在最多三個背景行程中進行部分搜尋，讓 Blender 保持流暢。使用填補工具時啟動，離開填補工具時結束。
「修正面屬性」開啟時，新面的 UV 從外框旁的面延伸；外框跨過 UV 縫線或部分外框旁沒有面時會提醒。
三角孔會生成一個三角面；其他奇數邊的外框會留一個三角面並以黃色標示。
自我交叉、重複點或來回折返的外框會立即被拒絕，並在外框上標出問題位置。其他複雜或扭曲的外框不一定有可用樣板；若會折疊，會拒絕填補，請按 Ctrl＋滾輪換方案或分割外框。

### 多面板填補

同時選取兩個以上封閉、沒有面的外框（面板），按住 Ctrl 即可一起預覽、一起填補，整次填補只有一個復原步驟。
面板可以共用邊：共用的邊（接縫）兩側直接使用同一批現有頂點，不會另外產生接縫頂點。
所有選取的邊都必須屬於某個面板外框（不可有懸空的連接邊）；接縫上位置重疊但彼此分開的頂點，要先合併。
預覽會顯示面板數、共用接縫數與面數。只要有一個面板無法填補，就不會新增任何面。
