# PolyTailor icons (pixel grid)

Eight icons: Build, Fill, Tweak, Relax, Pin, Unpin, Glue and Unglue.

Drawing rules: line-art mesh in the main color, one orange accent for what the tool
does (the brush, the grabbed vertex, the new quad, the pin, the joint). Secondary
parts (an existing strip, a released pin) use an opaque gray. 256-unit canvas (VCO
grid) laid on a 16 x 16 pixel grid, as Blender's own icons are: one pixel is 16
units, straight lines run at 16k + 8 with 16-unit strokes, so they fall on whole
pixels at 16, 32 and 48 px. Round caps and joins. Checked at 16, 20, 24, 32 and
128 px on dark and light backgrounds.

Palettes (main / gray / accent):
- dark: 229 gray / 130 gray / (255, 158, 52)
- light: 45 gray / 100 gray / (214, 104, 0)

- `<key>-icon.png` / `<key>_light-icon.png`: 32 px menu previews and GPU textures.
- `vector/<key>.prim`: the icon as vector primitives (capsules, rings, convex quads,
  roles main / dim / accent, drawing order). The W wheel draws these with a shader:
  each pixel is covered by its exact distance to the shapes, at any size, without
  rasterizing per size. Colors (add-on preferences > Icon Colors): Custom
  (default) uses three editable colors (defaults: the dark palette above); Native
  uses the widget's text color (selected text when chosen), that color at reduced
  alpha for secondary parts, and the Accent Color with the theme's icon
  saturation, alpha and border, like Blender's own icons.
- `vector/<key>.dat`: VCO geometry (dark palette) of Pin, Unpin, Glue and Unglue; Build,
  Fill, Tweak and Relax use their dark toolbar file below instead. The wheel's
  fallback when the shader is unavailable: rasterized at the exact pixel size, the
  dark palette mapped to the light palette on light themes.
- `<key>_<hash>.dat`: native toolbar VCO v0 triangle geometry, dark and light. The
  hash is of the geometry itself, so Blender never keeps an obsolete toolbar glyph.
- `toolbar_icons.txt`: alias -> geometry filename, including light variants.

Everything here is generated by the author's icon builder, which is not part of this
package.

Native menus choose the dark/light variant from widget theme colors. Toolbar
geometry is chosen when tools register (including re-enabling the add-on).

Format reference: https://github.com/blender/blender/blob/main/release/datafiles/blender_icons_geom.py
