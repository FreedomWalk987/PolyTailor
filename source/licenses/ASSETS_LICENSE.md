## PolyTailor icon family

The Poly Toolset 1.0.0 release replaced the custom tool artwork with the original
icon family (now PolyTailor's). The current icons are Build, Fill, Relax, Tweak,
Pin, Unpin, Glue and Unglue. They and their PNG/VCO derivatives follow this
project's existing CC0 dedication.

The icons are generated by the author's icon builder (run in Blender), which is
not included in the installable package. `icons/icon_sources.json` records hashes.

See `icons/README.md` for formats and icon colors.
